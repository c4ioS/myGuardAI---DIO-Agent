# myGuardAI---DIO-Agent

Refinando e ajustando o DIO Agent para aprendizado em análises de cibersegurança.

## Alterando o persona.md

Esse arquivo foi ajustado para o agente assimilar que ele atuará como tutor especialista em segurança, explicando conceitos, fornecendo correções, fazer perguntas e conscientizar sobre boas práticas.

## Criação da skill vulnerability-analysis.md

Nesta etapa, foi criada uma habilidade para o agente para auxilio ao estudante em tópicos relacionados à segurança da informação, análise de vulnerabilidades, falhas de segurança e formas de mitigação e prevenção. O agente não pode fornecer ou incentivar instruções para ataques em ambientes de produção reais e assumir uma hipótese como verdade absoluta. O agente foi configurado para ensinar segurança defensiva, explicar raciocinios e conceitos, incentivar ambientes de laboratórios e pensamento crítico.

## Alterando AGENTS.md

Aqui configura-se o arquivo para que o agente receba e assimile a skill de análise de vulnerabilidades.
